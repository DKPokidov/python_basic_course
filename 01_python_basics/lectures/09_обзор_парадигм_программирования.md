# Обзор парадигм программирования в Python

> Императивный, ООП, Функциональный — один язык, много подходов

---

## Что такое парадигма программирования?

> **Парадигма** — совокупность идей, концепций и принципов, которые определяют стиль написания программ и структурирования кода.

**Ключевая мысль:**

> Python — **многопарадигменный** язык. Он не заставляет использовать одну парадигму, а позволяет выбирать лучший инструмент для конкретной задачи.

```
┌─────────────────────────────────────────────┐
│              PYTHON                         │
│         (многопарадигменный)                │
│                                             │
│     ┌──────────┐                            │
│     │ Императи-│  "Как делать"              │
│     │ визм     │  шаг за шагом              │
│     └────┬─────┘                            │
│          │                                  │
│     ┌────┴─────┐  "Из чего состоит мир"    │
│     │   ООП    │  объекты + взаимодействия  │
│     └────┬─────┘                            │
│          │                                  │
│     ┌────┴─────┐  "Что хотим получить"       │
│     │ Функцио- │  преобразования данных     │
│     │ нальный  │                            │
│     └──────────┘                            │
└─────────────────────────────────────────────┘
```

---

## Императивное программирование

> **Основная идея:** Программа — это последовательность команд (инструкций), которые изменяют состояние программы. Мы говорим компьютеру **как именно делать** шаг за шагом.

**Что используем в Python:**

| Конструкция | Пример |
|-------------|--------|
| Присваивание переменных | `x = 5` |
| Ветвление | `if ... else` |
| Циклы | `for`, `while` |

---

## Функциональное программирование

> **Основная идея:** Программа — это вычисление результатов функций, а не изменение состояний. Мы описываем **что** мы хотим получить, а не **как**.

**Важно!**

> Python не является чисто функциональным языком, но он предоставляет инструменты для использования этого стиля.

---

## Объектно-ориентированное программирование (ООП)

> **Основная идея:** Программа — это набор взаимодействующих объектов. Каждый объект — экземпляр класса, который описывает его свойства (атрибуты) и поведение (методы).

**Почему это удобно?**

| Преимущество | Описание |
|-------------|----------|
| **Повторное использование кода** | Один класс → множество объектов |
| **Надёжность** | Изменения в одном объекте не влияют на другие |
| **Лёгкость понимания** | Код организован в виде объектов и их взаимодействий |

```
    ┌──────────┐         ┌──────────┐
    │  Класс   │         │  Класс   │
    │   Cat    │         │   Dog    │
    ├──────────┤         ├──────────┤
    │ name     │         │ name     │
    │ age      │         │ age      │
    ├──────────┤         ├──────────┤
    │ speak()  │         │ speak()  │
    │ purr()   │         │ bark()   │
    └────┬─────┘         └────┬─────┘
         │                    │
    ┌────┴─────┐         ┌────┴─────┐
    │ cat1     │         │ dog1     │
    │ cat2     │         │ dog2     │
    └──────────┘         └──────────┘
      экземпляры            экземпляры
```

---

## Почему Python многопарадигменный?

**Выбор инструмента под задачу:**

| Задача | Рекомендуемый стиль |
|--------|---------------------|
| Скрипт для автоматизации | Императивный |
| Сложное приложение с сущностями (игра, CRM) | ООП |
| Обработка данных, математические вычисления | Элементы ФП |

> Вы не ограничены одним стилем. Вы можете комбинировать их в рамках одного проекта для достижения лучшего результата: **читаемости**, **производительности** и **простоты поддержки**.

---

## Итоги

| Парадигма | Суть |
|-----------|------|
| **Императивная** | Программа как последовательность инструкций |
| **Объектно-ориентированная** | Программа как взаимодействие объектов |
| **Функциональная** | Программа как поток преобразований данных |

> Python поддерживает все три парадигмы, позволяя разработчику выбирать наиболее подходящий и эффективный стиль для решения задачи.
