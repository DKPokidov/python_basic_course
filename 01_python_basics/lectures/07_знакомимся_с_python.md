# Знакомимся с Python

---

## Философия Python

Автор языка — **Guido van Rossum**, нидерландский программист.

Философия Python (The Zen of Python):

| Принцип | Суть |
|---------|------|
| Красивое лучше, чем уродливое | Эстетика кода имеет значение |
| Явное лучше, чем неявное | Явный код понятнее скрытых механизмов |
| Простое лучше, чем сложного | Избегай ненужной сложности |
| Сложное лучше, чем запутанное | Сложность допустима, но не хаос |
| Читаемость имеет значение | Код пишут для людей, не только для машин |

> **Python** — высокоуровневый «человекочитаемый» язык программирования, который для вывода результатов использует интерпретатор.

---

## Забавный факт

> Название языку **Python** было дано в честь популярного британского комедийного шоу «Летающий цирк Монти Пайтона» (Monty Python's Flying Circus). Упоминания об этом можно найти в документации по языку.

## Преимущества Python

| Преимущество | Описание |
|-------------|----------|
| **Бесплатен** | Свободно распространяемое ПО с открытым исходным кодом |
| **Лёгок в изучении** | Простой синтаксис |
| **Лёгок в обслуживании** | Модульная структура |
| **Богатый арсенал** | Большая стандартная библиотека |
| **Портируемый** | Работает на обширном множестве платформ с одинаковым интерфейсом |
| **Интерпретируемый** | Компиляция не требуется |
| **Универсален** | Поддерживает процедурный и ООП-стили программирования |
| **Гибок** | Консольные программы, GUI-приложения и многое другое |
