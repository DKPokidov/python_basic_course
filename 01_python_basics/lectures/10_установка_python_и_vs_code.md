## Установка Python в операционной системе

### Шаг 1: Загрузка установщика

1. Запустите веб-браузер
2. Перейдите на страницу **[python.org](https://python.org)**
3. Загрузите установщик, подходящий для вашей версии операционной системы

---

### Шаг 2: Запуск установщика

Исполнить можно и так:
- Дважды кликните по скачанному файлу

А можно через командную строку:
```cmd
python-3.x.x-amd64.exe /passive InstallAllUsers=0 PrependPath=1
```

> По умолчанию Python устанавливается по пути:
> ```
> C:\Users\<Пользователь>\AppData\Local\Programs\Python\Python3xx\python.exe
> ```

---

### Шаг 3: Настройка установки

1. Выберите вариант **«Customize installation»**
2. **Обязательно** поставьте галочку **«Add python.exe to PATH»** — это позволит запускать Python из любой папки на вашем компьютере, что критически важно для удобной работы

---

### Шаг 4: Финальные настройки

- Запомните путь установки
- Поставьте галочку **«Install for all users»**
- Нажмите **«Install»** и дождитесь окончания установки

> **Путь по умолчанию:**
> ```
> C:\Users\<Пользователь>\AppData\Local\Programs\Python\Python3xx\
> ```

---

## Устанавливаем Visual Studio Code

### Загрузка

- Для **Windows** — кликните по соответствующей кнопке на [code.visualstudio.com](https://code.visualstudio.com)
- Для других ОС — выберите нужный вариант

> Процесс установки очень простой. Можно смело нажимать **«Next»**, оставляя все настройки по умолчанию. Рекомендуется оставить все галочки.

---

## Настраиваем VS Code

### Открываем VS Code

- Через ярлык на рабочем столе
- Или через меню «Пуск»

### Устанавливаем расширение Python

1. Нажмите на иконку **квадратов** в левой боковой панели или используйте горячие клавиши `Ctrl + Shift + X`
2. В поисковой строке введите **Python**
3. Найдите расширение **«Python»** от Microsoft и нажмите **«Install»** (Установить)

---

### Создаём проект

1. Создайте на диске **новую папку** с понятным названием
2. Откройте папку в VS Code:
   - Нажмите **File** → **Open Folder**
3. Создайте новый файл:
   - Наведите курсор на боковую панель с названием вашей папки
   - Нажмите иконку **«New File…»**
4. Назовите файл, обязательно указав расширение `.py`, например `hello.py`

---

## Пишем свой первый код

### Запуск программы

1. Напишите код в файле `hello.py`:

```python
print("Hello, World!")
```

2. **Не забываем сохранить** перед запуском: `Ctrl + S`
3. Нажмите **правой кнопкой мыши** в любом месте редактора с кодом и выберите **«Run Python File in Terminal»**

> А вот и результат выполнения программы!
