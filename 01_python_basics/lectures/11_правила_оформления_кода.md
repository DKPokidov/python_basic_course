# Правила оформления кода

> Или как сделать так, чтобы другие разработчики вас понимали

## Стиль программирования

**Стиль программирования** — дополнительные ограничения, накладываемые на структуру и вид программного кода группой совместно работающих программистов с целью получения удобных для применения, легко читаемых и эффективных программ.

Рекомендации по написанию «правильного» Python-кода создатели языка изложили в документе **PEP 8** — *Style Guide for Python Code*.

> **PEP** расшифровывается как *Python Enhancement Proposal* — «Предложение по улучшению Python».

---

## Правила стиля: пробелы вокруг операторов

> Бинарные операторы **всегда** окружаются одним пробелом с каждой стороны.

### Какие операторы считаются бинарными:

| Категория | Примеры |
|-----------|---------|
| **Присваивания** | `=`, `+=`, `-=`, `*=`, `/=`, `//=` и др. |
| **Сравнения** | `==`, `<`, `>`, `!=`, `<=`, `>=`, `in`, `not in`, `is`, `is not` |
| **Логические** | `and`, `or`, `not` |

### Примеры

```python
# Правильно
x = 5
y += 10
if a == b and c != d:
    pass

# Неправильно
x=5
y+=10
if a==b and c!=d:
    pass
```

## Правила стиля: арифметические операторы

В отношении арифметических операторов (`+`, `-`, `*`, `**`, `%`, `//`) рекомендация более тонкая:

> Если используются операторы с **разными приоритетами**, рассмотрите возможность добавления пробелов вокруг операторов с **наименьшим приоритетом**.

### Правила

- Никогда не используйте **больше одного пробела**
- Всегда ставьте **одинаковое количество пробелов** с обеих сторон оператора

### Примеры

```python
# Правильно
result = x*2 - 3
c = a + b*2
y = x**2 + 1

# Неправильно
result = x * 2-3
c = a+b * 2
```

## Правила стиля: знак «равно»

### Именованные аргументы и значения по умолчанию

Если знак `=` используется для обозначения **именованного аргумента** или **значения по умолчанию** (внутри скобок), пробелы вокруг него **не ставятся**:

```python
# Правильно
def greet(name, greeting="Привет"):
    print(greeting, name)

func(x=10, y=20)

# Неправильно
def greet(name, greeting = "Привет"):
    print(greeting, name)
```

### Запятая и двоеточие

- **Перед** запятой и двоеточием пробел **не ставится**
- **После** запятой и двоеточия пробел **ставится**

```python
# Правильно
my_dict = {"a": 1, "b": 2}
my_list = [1, 2, 3]
if x: pass

# Неправильно
my_dict = {"a" :1, "b" :2}
my_list = [1 ,2 ,3]
if x :pass
```

## Правила стиля: комментарий

> Комментарий лучше писать в **отдельной строке**.

### Правила оформления комментариев

- Начинается со знака `#` **и пробела**
- Строка комментария **не должна быть длиннее 72 символов**
- Если комментарий в той же строке, что и инструкция — отделяется **минимум двумя пробелами**

```python
# Правильно: комментарий в отдельной строке
x = 5  # Вычисляем значение

# Неправильно: нет пробела после #
#x = 5

# Неправильно: комментарий без отступа от кода
x = 5 #комментарий

# Правильно: минимум два пробела перед inline-комментарием
x = 5  # задаём значение
```

## Правила стиля: отступы решают

> Рекомендуется использовать отступы в **4 пробела**.

### Почему это важно?

В Python уровень вложенности определяется **только отступами**, поэтому количество отступов в многострочных конструкциях **критически важно**.

```
┌─────────────────────────────────────────────┐
│  Нарушение отступов → SyntaxError           │
│  Это хорошо — ошибка видна сразу            │
│                                             │
│  Хуже, если программа НЕ сообщит об ошибке  │
│  и выполнит неверно написанный код          │
└─────────────────────────────────────────────┘
```

```python
# Правильно: 4 пробела
def greet(name):
    if name:
        print(f"Привет, {name}!")

# Неправильно: смешение отступов
def greet(name):
	if name:          # табуляция вместо пробелов
		print(name)  # двойной отступ
```

## Правила стиля: перенос строки

> Длина строки кода **не должна превышать 79 символов**.

### Способы разбиения длинных строк

**Неявное разбиение** — внутри скобок (предпочтительно):

```python
result = some_function(argument_one, argument_two,
                       argument_three, argument_four)

my_list = [
    "first element",
    "second element",
    "third element",
]
```

**Явное разбиение** — с помощью обратного слэша `\`:

```python
if (condition_one
        and condition_two
        and condition_three):
    do_something()
```

> Если смысл оператора при этом становится неочевидным, или такое разбиение невозможно — используется обратный слэш.

## Правила стиля: нерекомендуемые символы

> Не рекомендуется использовать следующие символы в качестве **односимвольных имён переменных**:

| Символ | Буква | Почему проблематично |
|--------|-------|---------------------|
| `l` (строчная) | Эл | Неотличима от `1` в некоторых шрифтах |
| `O` (прописная) | Оу | Неотличима от `0` в некоторых шрифтах |
| `I` (заглавная) | Ай | Неотличима от `1` в некоторых шрифтах |

> Когда возникает искушение использовать букву `l` (строчная «эл»), используйте вместо неё букву `L` (заглавная «эл»).

## Правила стиля: не баг, а фича

> Последней строкой в модуле с программой должна быть **пустая строка**.

```
┌──────────────────────────────────────────────┐
│  Текстовые редакторы:  пустой параграф в     │
│  конце текста = нарушение правил             │
│                                              │
│  Python: пустая строка в конце программы =   │
│  ЭТО ПРАВИЛО                                 │
└──────────────────────────────────────────────┘
```

```python
# Правильно: пустая строка в конце файла
def main():
    print("Hello!")

if __name__ == "__main__":
    main()
    # ← здесь должна быть пустая строка
```

## Сводка: PEP 8 — ключевые правила

| Правило | Краткое описание |
|---------|-----------------|
| **Пробелы вокруг операторов** | Один пробел с каждой стороны бинарных операторов |
| **Арифметические операторы** | Пробелы вокруг оператора с наименьшим приоритетом |
| **Знак `=`** | Без пробелов для именованных аргументов |
| **Запятая / двоеточие** | Без пробела перед, с пробелом после |
| **Комментарии** | Отдельная строка, `#` + пробел, ≤ 72 символа |
| **Отступы** | 4 пробела, не смешивать с табуляцией |
| **Длина строки** | Не более 79 символов |
| **Нерекомендуемые символы** | Избегать `l`, `O`, `I` как имён переменных |
| **Пустая строка в конце** | Обязательна |
