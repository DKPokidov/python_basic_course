# Информация и информационные процессы

---

## Что такое информация?

> **Информация** — данные, которые в определённой форме хранятся на каком-либо носителе.

---

## Свойства информации

| Свойство | Определение |
|----------|-------------|
| **Объективность** | Не зависит от чьего-либо мнения |
| **Достоверность** | Отражает истинное положение дел |
| **Полнота** | Достаточна для понимания и принятия решения |
| **Актуальность** | Важна и существенна в данный момент |
| **Понятность** | Выражена на языке, доступном для получателя |
| **Ценность** | Полезна для решения задач |

## Информационные процессы

```
┌────────────┐         ┌────────────────┐         ┌────────────┐
│  Источник  │ ──────► │ Канал связи    │ ──────► │  Приёмник  │
└────────────┘         └────────────────┘         └────────────┘
                         Передача
```

| Процесс | Описание |
|---------|----------|
| **Передача** | Источник → Канал связи → Приёмник |
| **Обработка** | Преобразование информации из одного вида в другой |
| **Хранение** | Сохранение информации для дальнейшего использования |
| **Поиск** | Извлечение хранимой информации |
| **Защита** | Предотвращение утери, искажения или несанкционированного доступа |

---

## Как видит информацию компьютер?

| Тип данных | Представление в компьютере |
|------------|---------------------------|
| **Текст** | Каждому символу (букве, цифре, знаку) присваивается уникальный числовой код (таблицы ASCII, Unicode) |
| **Числа** | Хранятся и обрабатываются в двоичной системе счисления |
| **Изображение** | Картинка разбивается на мелкие точки (пиксели). Каждый пиксель имеет свой числовой код, определяющий его цвет |
| **Звук** | Звуковая волна разбивается на отрезки, и для каждого измеряется и кодируется числом его интенсивность (амплитуда) |
