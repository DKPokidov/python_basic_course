# Взаимодействие с Python

---

## Что такое программа?

> **Программа** — алгоритм для исполнителя-компьютера, описанный на доступном ему языке.

---

## Языки программирования: компилируемые vs интерпретируемые

```
┌──────────────────────────────────────────────┐
│          КОМПИЛЯЦИЯ                          │
│                                              │
│  Исходный код ──► КОМПИЛЯТОР ──► .exe        │
│  (*.sb)                       (исполняемый)  │
│                                              │
│  Данные ──────► .exe ──────► Результат       │
├──────────────────────────────────────────────┤
│          ИНТЕРПРЕТАЦИЯ                        │
│                                              │
│  Исходный код ──► ИНТЕРПРЕТАТОР               │
│  (*.py в IDLE)                               │
│                                              │
│  Данные ──────► Интерпретатор ──► Результат  │
└──────────────────────────────────────────────┘
```

- **Компилируемые** — исполняемый файл выполняет только операции с данными. Быстрее.
- **Интерпретируемые** — интерпретатор помимо операций с данными распознаёт команды языка. Медленнее, но кроссплатформенны.

> Запустить интерпретируемую программу можно только на компьютере, где установлен Python.

## Взаимодействие с Python

Python предоставляет два основных режима работы.

---

## Интерактивный режим

Запускаем Python и получаем приглашение ввода `>>>`.

### Калькулятор

```python
>>> 3 + 2
5
>>> 12 + 3 * 8
36
>>> (12 + 3) * 8
120
>>> 2 ** 8
256
>>> 1234569999999 * 12658888888888
15628284455541799271111112
```

- **`**`** — возведение в степень
- Размер целых чисел в Python ограничивается **только размером памяти**
- Действуют стандартные **приоритеты операций**

### Сочетания клавиш в IDLE

| Сочетание клавиш | Назначение |
|-------------------|------------|
| `Alt + P` / `Alt + N` | Перемещение по истории сессии (назад / вперёд) |
| `Ctrl + Space` | Динамическая подсказка (имена функций, ключевые слова) |
| `Alt + /` | Автодополнение по первым буквам ранее использованных имён |
| `Ctrl + Delete` | Удаление целого слова справа от курсора |
| `Ctrl + Backspace` | Удаление целого слова слева от курсора |
| `Alt + 3` | Закомментировать выделенную строку |
| `Alt + 4` | Раскомментировать выделенную строку |

> **Совет:** Если `Ctrl + V` не работает в Python Shell — переключитесь на EN раскладку или используйте *Edit → Paste*.

## Строки в интерактивном режиме

```python
>>> print('Cat' + 'Mouse')
CatMouse
>>> print('cat' * 10)
catcatcatcatcatcatcatcatcatcat
```

- Строки могут отделяться **кавычками** (`"..."`) или **апострофами** (`'...'`)
- Строки можно **умножать** на число
- `print(то, что надо вывести)` — выводит значение на экран

> Кавычки интерпретатор Python понимает буквально и выводит то, что заключено между ними. При отсутствии кавычек интерпретатор пытается определить значение как выражение.

---

## Цветовое выделение и ошибки

```python
>>> print('Привет, добро пожаловать в Python')
```

Python выделяет разными цветами разные части кода. Ключевое слово (`print`) и строки различаются визуально.

```python
>>> prent('Привет')
NameError: name 'prent' is not defined
```

Если введена директива, которую Python не может понять — он сообщит об ошибке. `prent` вместо `print` — это опечатка, не ключевое слово.

---

## Конкатенация строк

> Глагол «складывать» не совсем корректен, когда речь идёт о строках.

Для обозначения процесса стыковки символов или строк используется термин **конкатенация**.

```python
>>> 'Hello' + ' ' + 'World'
'Hello World'
```

> **Примечание:** Слово «сложение» допустимо только для чисел. Для строк — **конкатенация**.

## Программный режим

В интерактивном режиме удобно экспериментировать, но для реальных программ используем **программный режим** — файлы с расширением `.py`.

---

## Первая программа в редакторе

1. Откройте редактор IDLE: *File → New File*
2. Напишите код
3. Сохраните файл с расширением `.py`
4. Запустите: *Run → Run Module* (или `F5`)

> Работаем с двумя окнами — **окном файла** и **окном исполнения**.

## Если что-то идёт не так: ошибки в Python

> Ошибки в программах часто называются **багами** (от англ. *bug* — жук), а процесс их отслеживания — **отладкой** (англ. *debugging*).

### Типы ошибок

| Тип ошибки | Когда возникает | Интерпретатор |
|-----------|-----------------|---------------|
| **Синтаксическая** | Код не соответствует правилам языка (например, нет кавычек) | Останавливается **до** выполнения |
| **Ошибка выполнения** (исключение) | Во время исполнения (например, несовпадение типов) | Останавливается **во время** выполнения, сообщает об исключении |
| **Логическая** (смысловая) | Программа работает, но результат неверен (например, не определён порядок действий) | **Не сообщает** об ошибке |

---

## Синтаксическая ошибка

```python
>>> print('Hello"
  File "<stdin>", line 1
    print('Hello"
               ^
SyntaxError: EOL while scanning string literal
```

Интерпретатор останавливается и сообщает об ошибке **без дальнейшего выполнения** программы.

---

## Ошибка выполнения

```python
>>> 'До свидания' + 5
TypeError: can only concatenate str (not "int") to str
```

Интерпретатор запускает программу, останавливается на ошибке и сообщает о природе этой ошибки как об **исключении**.

**Пример из лекции:** `print('До свидания' * 5)` — работает, а `print('До свидания' + 5)` — нет.

> В Python нельзя сложить два объекта **разных типов**.

---

## Логическая ошибка

```python
>>> result = 2 + 3 * 4
# Ожидалось (2+3)*4 = 20, получилось 2 + 12 = 14
```

Интерпретатор **не сообщает** об ошибке — программа выполняется, но результат не тот, который ожидался.

## Система помощи Python

Используйте встроенные средства помощи:

- `help()` — запуск интерактива справки
- `help(print)` — справка по конкретной функции
- `dir()` — список доступных имён
- `type(объект)` — тип объекта

## Выводы

- **Python** — высокоуровневый язык программирования, использующий интерпретатор для вывода результатов
- **Интерактивный режим** — позволяет проверять куски кода, полезен для отладки
- **Программа на Python** — текстовый файл с расширением `.py`, созданный в текстовом редакторе
- **`print()`** — выводит на экран строку, указанную внутри скобок
- Строковые значения должны быть заключены в **кавычки**
- **Синтаксические ошибки** распознаются интерпретатором **до** исполнения программы
- **Ошибки исполнения** распознаются интерпретатором **во время** исполнения программы
- **Смысловые ошибки** **не распознаются** интерпретатором
