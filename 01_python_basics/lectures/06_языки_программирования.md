# Языки программирования

## Два слова о программировании

Ну, ладно, не два — немного больше, зато они полезные.

---

## Что такое язык программирования?

> **Язык программирования** — формальная знаковая система, используемая для связи человека с процессором.

Язык программирования определяет набор:

- **Лексических** правил (допустимые слова и символы)
- **Синтаксических** правил (как складывать конструкции)
- **Семантических** правил (что означают конструкции)

---

## Два основных способа выполнения кода

| | Компилируемые языки | Интерпретируемые языки |
|---|---|---|
| **Примеры** | C, C++, Go, Rust | Python, JavaScript, PHP |
| **Аналогия** | Перевод всей книги перед публикацией | Синхронный переводчик |
| **Как работает** | Компилятор целиком читает код, проверяет на ошибки и преобразует в машинный код (`.exe`) | Интерпретатор читает код построчно, сразу выполняет и выдаёт результат |
| **Скорость** | Высокая | Более низкая |
| **Кроссплатформенность** | Нужно компилировать под каждую ОС отдельно | Да |

```
┌─────────────────────────────────────────────────┐
│            КОМПИЛЯЦИЯ                          │
│                                                 │
│  Исходный код ──► Компилятор ──► .exe ──► Результат │
│  (целиком)        (проверяет)    (файл)          │
├─────────────────────────────────────────────────┤
│            ИНТЕРПРЕТАЦИЯ                        │
│                                                 │
│  Исходный код ──► Интерпретатор ──► Результат   │
│                 (строка за строкой)              │
└─────────────────────────────────────────────────┘
```

## Почему языков так много?

Разные задачи — разные инструменты:

| Язык | Область применения |
|------|-------------------|
| Java | Мобильные приложения, веб-сервисы, корпоративные системы |
| JavaScript | Веб-страницы |
| Python | Data Science, AI |
| Swift / Kotlin | Мобильные приложения |
| C / C++ | ОС, драйверы, игры (скорость критична) |

Причины многообразия:

- **Разные философии и парадигмы** программирования
- **Технологический прогресс** порождает новые задачи
- **Экосистема и сообщество** вокруг каждого языка

## Основные понятия языка программирования

| Понятие | Описание |
|---------|----------|
| **Имена (идентификаторы)** | Обозначают объекты программы: переменные, списки, функции и др. |
| **Данные** | Величины, обрабатываемые программой; бывают разных типов |
| **Выражения** | Состоят из констант, переменных, вызовов функций, объединённых знаками операций |

### Операции

- **Арифметические:** `+`, `-`, `*`, `/`, `%`, `**`
- **Логические:** `and`, `or`, `not`
- **Отношения:** `<`, `>`, `<=`, `>=`, `==`, `!=`
- **Конкатенация (сцепка):** склеивание строк

## Почему мы учим Python?

- **Читаемый синтаксис** — код похож на псевдокод, минимум лишних символов
- **Низкий порог входа** — можно быстро начать и получить первый результат
- **Огромная стандартная библиотека** и сообщество — для большинства задач уже есть готовые решения
- **Универсальность** — анализ пространственных данных, разработка модулей, AI
