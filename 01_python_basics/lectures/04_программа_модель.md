# Программа – информационная модель

---

## Что такое «программа»?

Программа — последовательность действий. Это понятие используется в разных контекстах:

- Программа для компьютера
- Программа конференции
- Программа учебного курса
- Программа «Деликатная стирка»
- Программа партии
- Программа телепередач
- Программа для станка с ЧПУ

---

## Это программа?

Посмотрим на список действий:

1. Почесать левое ухо
2. Сказать «Ку-ку!»
3. Встать со стула
4. Перевернуть стол ножками кверху
5. Подойти к окну и посмотреть на небо
6. Почесать правое ухо
7. Достать то, что лежит в левом кармане, и переложить в правый карман
8. 100 раз сказать «Зенит-чемпион!»
9. Почесать левую пятку
10. Вернуться к своему месту

> **Вопросы:**
> - Это программа?
> - Чего не хватает, чтобы это стало программой?
> - Если программа должна приводить к достижению какой-то цели — какая цель у компьютерной программы?

---

## На этом занятии

- Разберёмся с понятиями «модель», «объект», «система»
- Поработаем с различными информационными моделями
- Создадим кое-какие собственные информационные модели
- Выясним, что такое «информационный процесс», встретимся с понятиями «данные» и «алгоритм»

---

## Что такое модель?

> **Модель** — образ объекта, отражающий его существенные свойства и служащий для принятия решений.

```
┌──────────┐        ┌──────────┐        ┌──────────────────┐
│  Объект  │ ─────► │  Модель  │ ─────► │ Принятие решения │
└──────────┘        └──────────┘        └──────────────────┘
```

---

## Виды моделей

> В каких формах может быть представлена информация?

| Тип модели | Форма представления | Пример |
|------------|-------------------|--------|
| **Числовая** | Таблицы, формулы, статистика | Рост, вес, температура |
| **Графическая** | Схемы, диаграммы, рисунки | Карта, чертёж, фотография |
| **Вербальная** | Текст, описания, формулировки | Инструкция, рассказ, определение |

---

## Примеры моделей

Моделируемый объект — **ВЫ**:

| Тип модели | Как представить себя |
|------------|---------------------|
| **Числовая** | Рост, вес, возраст, группа крови… |
| **Графическая** | Фотография, автопортрет, схема… |
| **Вербальная** | «Я — студент(ка) ИТМО, люблю…» |

## Простые и сложные объекты

### Простые объекты

| Объект | Свойство |
|--------|----------|
| Гиря | Вес |
| Болт (гайка) | Вес |

### Сложные объекты (системы)

| Объект | Свойство |
|--------|----------|
| Набор гирь | Вес |
| Болт и гайка | Пригодность для соединения деталей |

> **Важно:** Свойство болта и гайки (пригодность для соединения) **не является суммой** свойств составных частей!

---

## Система

> **Система** — совокупность элементов, взаимодействующих друг с другом и таким образом являющихся единым целым с общей целью функционирования.

```
┌─────────────────────────────────────────────────────────────┐
│                    ПРИНЦИП ЭМЕРДЖЕНТНОСТИ                    │
├─────────────────────────────────────────────────────────────┤
│  Свойства системы ≠ Сумма свойств элементов                 │
└─────────────────────────────────────────────────────────────┘
```

### Ключевые понятия

| Понятие | Определение |
|---------|-------------|
| **Элемент системы** | Часть системы, выполняющая определённую функцию |
| **Подсистема** | Сложный элемент, состоящий из взаимосвязанных частей |
| **Организация системы** | Согласованность действий её элементов (функции и правила существования элементов) |
| **Структура системы** | Совокупность устойчивых связей и взаимоотношений между элементами |

## Система и среда

```
┌─────────────────────────────────────────────────────────────┐
│                        СРЕДА                                 │
│    ┌───────────────────────────────────────────────────┐    │
│    │  ВХОД ──────►┌─────────┐──────► ВЫХОД             │    │
│    │              │ СИСТЕМА │                           │    │
│    └──────────────┴─────────┴──────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

- **Закрытые материальные системы** — взаимодействием со средой можно пренебречь
- **Закрытых информационных систем не бывает** — они всегда взаимодействуют со средой

## Информационная модель

```
┌──────────────────┐                                    ┌──────────────────┐
│  Входные данные  │ ─────────────────────────────────► │  Выходные данные │
└──────────────────┘         Информационный             └──────────────────┘
                             процесс
```

## Программа = Информационная модель + Алгоритм

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Последовательность действий        Информационная модель  │
│      (алгоритм)                                                    │
│                                                             │
│   ┌───────────┐              ┌───────────────────────┐      │
│   │ АЛГОРИТМ  │     +        │ ИНФОРМАЦИОННАЯ МОДЕЛЬ │      │
│   └───────────┘              └───────────────────────┘      │
│              ╲                  ╱                           │
│               ╲                ╱                            │
│            ┌─────────────────────┐                          │
│            │     ПРОГРАММА       │                          │
│            └─────────────────────┘                          │
│                                                             │
│              ИНФОРМАЦИОННЫЙ ПРОЦЕСС                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

> Когнитивный диссонанс исчерпан. Переходим к упражнениям.
