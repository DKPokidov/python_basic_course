## Определение алгоритма

```
┌─────────────────────────────────────────────────────────────────┐
│                         АЛГОРИТМ                                │
├────────────────────────────────┬────────────────────────────────┤
│    В широком смысле            │  С точки зрения программиста   │
├────────────────────────────────┼────────────────────────────────┤
│  Описание последовательности   │  Описание способа получения    │
│  действий для достижения цели  │  выходных данных из входных    │
└────────────────────────────────┴────────────────────────────────┘
```

---

## Информационная модель

```
┌──────────────────┐          ┌──────────────────┐
│  Входные данные  │ ───────► │  Выходные данные │
└──────────────────┘    ↑     └──────────────────┘
                        │
               Способ получения
              выходных данных из входных
```
