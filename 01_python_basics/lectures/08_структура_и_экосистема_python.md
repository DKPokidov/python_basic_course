# Структура и экосистема Python

## Что окружает язык?

1. **Стандартная библиотека** — «Батарейки в комплекте»

4. **Сторонние библиотеки** — примеры из разных сфер

## Стандартная библиотека

> **«Батарейки в комплекте»** — огромная коллекция модулей и пакетов, которые поставляются вместе с интерпретатором Python. Ничего дополнительно устанавливать не нужно.

**Философия:** предоставить готовые решения для большинства стандартных задач.

> **Правило хорошего тона!**
> Прежде чем писать код с нуля или искать стороннюю библиотеку — проверь, нет ли решения в стандартной библиотеке.

### Примеры модулей

| Категория | Модуль | Назначение |
|-----------|--------|------------|
| **Данные** | `math` | Математические функции |
| | `random` | Генерация случайных чисел |
| | `datetime` | Работа с датой и временем |
| **Система** | `os` | Взаимодействие с ОС |
| | `sys` | Доступ к параметрам интерпретатора |
| **Сеть** | `urllib.request` | Простые HTTP-запросы |

## PyPI и pip — «Магазин приложений» для Python

### PyPI (Python Package Index)

Огромный онлайн-репозиторий стороннего ПО для Python — главный каталог, где разработчики со всего мира публикуют свои библиотеки.

### pip (Pip Installs Packages)

Консольная утилита (менеджер пакетов):

| Команда | Действие |
|---------|----------|
| `pip install requests` | Установить пакет |
| `pip uninstall requests` | Удалить пакет |
| `pip list` | Показать список установленных пакетов |

## Зачем нужны виртуальные окружения (venv)?

### Проблема

Вы работаете над двумя проектами. Проекту №1 нужна библиотека `requests` версии **2.25**, а Проекту №2 — версии **3.0**. Глобальная установка через `pip` разрешит только одну версию для всех проектов. **Конфликт!**

### Решение

> **Виртуальное окружение** — изолированная среда для каждого проекта со своими зависимостями и своими версиями пакетов.

```
┌───────────────────────────────────────────────┐
│              СИСТЕМА (глобальная)              │
│                                               │
│  ┌─────────────────┐  ┌────────────────────┐  │
│  │ Проект №1       │  │ Проект №2          │  │
│  │ venv/           │  │ venv/              │  │
│  │ ├─ requests 2.25│  │ ├─ requests 3.0    │  │
│  │ └─ flask        │  │ └─ django          │  │
│  └─────────────────┘  └────────────────────┘  │
│         ▲                       ▲              │
│         └───── изоляция! ───────┘              │
└───────────────────────────────────────────────┘
```

## Итоги

| Компонент | Роль |
|-----------|------|
| **Стандартная библиотека** | Первый и главный помощник |
| **PyPI + pip** | Бескрайний источник готовых решений и инструмент для их установки |
| **Виртуальные окружения** | Обязательный инструмент для изоляции зависимостей и порядка |

> Вместе они образуют мощную и зрелую экосистему, которая делает Python таким популярным.
