# Алгоритм: свойства и формы записи

---

## Разминка

Из словесного описания некого алгоритма убрали все слова, кроме глаголов. Осталось вот что:

```
ВКЛЮЧИТЬ → ПОСТАВИТЬ → КАПНУТЬ → НАРЕЗАТЬ → ПОЛОЖИТЬ
→ ПЕРЕВЕРНУТЬ → РАЗБИТЬ → ПОСОЛИТЬ → ПОДОЖДАТЬ → ВЫКЛЮЧИТЬ → СНЯТЬ
```

> **Вопрос:** Что будет результатом выполнения исходного алгоритма?

## Определение алгоритма

### Формулировка

> **Алгоритм** — формальное описание последовательности действий для достижения цели.

### Является ли алгоритмом…?

| Пример | Алгоритм? |
|--------|-----------|
| Раздел «Подготовка к работе» в инструкции к стиральной машине | Да |
| Конституция США | Нет |
| Технология изготовления детали на металлорежущем станке | Да |
| Маршрут, построенный навигатором | Да |
| Ответ на вопрос «Как добраться до ближайшей станции метро?» | Да |
| Книга Дейла Карнеги «Как перестать беспокоиться и начать жить» | Нет |
| Глава в учебнике про умножение и деление в столбик | Да |

## Исполнитель алгоритма

**Исполнитель алгоритма** — человек или автоматическое устройство, которому предстоит осуществить описываемую последовательность действий.

### Требования к исполнителю

```
┌─────────────────────────────────┐
│        ИСПОЛНИТЕЛЬ              │
│                                 │
│  1. Хранить алгоритм в памяти   │
│  2. Распознавать его команды    │
│  3. Быть в состоянии их         │
│     исполнять                   │
└─────────────────────────────────┘
```

### Размышления

- Является ли кофейный автомат исполнителем алгоритмов?
- Речь обо всём автомате или о его микропроцессоре?
- Что является входными данными? А выходными?
- А какая у него система команд?

## Формы записи алгоритма

Рассмотрим на примере **алгоритма нахождения наибольшего общего делителя** двух натуральных чисел (алгоритм Евклида).

```
Вход:  Два натуральных числа, A и B
Выход: Натуральное число, НОД(A, B)
```

> «Да легко! Просто вычитайте из большего меньшее, пока они не сравняются!»

---

## Словесная форма

### Алгоритм Евклида (словесный)

1. Ввести числа A и B.
2. Если A = B, то перейти к п. 8.
3. Если A > B, то перейти к п. 6.
4. `B := B − A` (вычесть из B значение A, результат записать в B)
5. Перейти к п. 2.
6. `A := A − B` (вычесть из A значение B, результат записать в A)
7. Перейти к п. 2.
8. Вывести значение A.
9. Закончить работу алгоритма.

## Блок-схема

```
        ┌─────────┐
        │  НАЧ    │
        └────┬────┘
             │
        ┌────▼────┐
        │ Ввод A,B│
        └────┬────┘
             │
        ◆────▼────◆
       /  A = B?   \
      /  ДА    НЕТ  \
     ◆──────┬────────◆
            │ДА
            │
        ┌───▼───┐
        │Вывод A│
        └───┬───┘
            │
        ◆───▼───◆
       / A > B?  \
      / ДА   НЕТ \
     ◆─────┬──────◆
           │
     ┌─────▼─────┐     ┌─────▼─────┐
     │ A := A − B│     │ B := B − A│
     └─────┬─────┘     └─────┬─────┘
           │                  │
           └────────┬─────────┘
                    │
                    ▼
              (к п. 2: A = B?)
                    
        ┌─────────┐
        │  КОН    │
        └─────────┘
```

## Язык программирования (Python)

### Тот же алгоритм на Python

```python
a = int(input("Введите A: "))
b = int(input("Введите B: "))

while a != b:
    if a > b:
        a = a - b
    else:
        b = b - a

print("НОД =", a)
```

## Сравнение форм записи

| Форма | Плюсы | Минусы |
|-------|-------|--------|
| **Словесная** | Понятна каждому | Многословна, трудно формализовать |
| **Блок-схема** | Наглядна, наглядная логика | Громоздка для сложных алгоритмов |
| **Псевдокод** | Близка к программированию | Нет единого стандарта |
| **Язык программирования** | Исполняется компьютером | Требует изучения синтаксиса |
