## Как работать с курсом

**1. Клонируйте репозиторий**
```bash
git clone https://github.com/DKPokidov/python_basic_course.git
cd python_basic_course
```

**2. Создайте ветку для своих заданий**
```bash
git checkout -b student/ваше_имя
```

**3. Выполняйте задания**
- Откройте задание в VS Code или Jupyter Notebook
- Напишите решение в месте `# НАПИШИТЕ ВАШ КОД ЗДЕСЬ`
- Сохраните файл

**4. Отправьте работу**
```bash
git add .
git commit -m "Выполнены задания: модуль N"
git push origin student/ваше_имя
```

**5. Создайте Pull Request** на GitHub из вашей ветки в `master`

> Подробную инструкцию по работе с Git и GitHub смотрите в лекции: [`01_python_basics/lectures/13_работа_с_git_и_github.md`](01_python_basics/lectures/13_работа_с_git_и_github.md)

## Как создать Pull Request: пошаговая инструкция

Pull Request (PR) — это запрос на объединение вашей ветки с заданиями в основную ветку `master`. Именно через PR вы сдаёте работы: преподаватель видит ваши решения, проверяет их автоматическими тестами и принимает или оставляет комментарии.

> Перед созданием PR убедитесь, что вы уже выполнили шаги 1–4 из раздела выше: склонировали репозиторий, создали ветку и сделали `git push`.

### Шаг 1. Откройте страницу вашей ветки

1. Зайдите на страницу репозитория курса: **[github.com/DKPokidov/python_basic_course](https://github.com/DKPokidov/python_basic_course)**
2. Откройте выпадающий список веток (кнопка с надписью **«master»** в левом верхнем углу)
3. Найдите и выберите **свою ветку** (например, `student/ваше_имя`)

### Шаг 2. Нажмите кнопку «Compare & pull request»

После выбора ветки GitHub предложит создать Pull Request:
- На вкладке **«Pull requests»** справа появится жёлтая кнопка **«Compare & pull request»**
- Либо сразу после пуша GitHub сам покажет кнопку вверху списка файлов

> Кнопка появится только в том случае, если вы уже сделали `git push origin ваша_ветка`.

### Шаг 3. Заполните форму Pull Request

Убедитесь, что поля заполнены правильно:

| Поле | Что должно быть |
|------|-----------------|
| **base** | `master` — куда будут добавлены ваши изменения |
| **compare** | `student/ваше_имя` — ваша ветка с решениями |
| **Title** (заголовок) | Например: «Выполнены задания: модуль 1» |
| **Description** (описание) | По желанию — кратко опишите, что сделали |

> Проверьте, что в форме указано «Able to merge» (можно объединить) — это значит, что конфликтов с основной веткой нет.

### Шаг 4. Создайте Pull Request

Нажмите зелёную кнопку **«Create pull request»**.

### Шаг 5. Что происходит после создания

- Автоматически запускаются **тесты**: проверка решений (`pytest`) и стиля кода (`flake8`)
- Результаты вы увидите внизу страницы PR в блоке **«Checks»** (зелёная галочка ✅ — всё прошло, красный крест ❌ — есть проблемы)
- Если тесты не прошли — откройте отчёт, найдите проблемные задачи, исправьте решение и повторно выполните:
  ```bash
  git add .
  git commit -m "Исправление: модуль N"
  git push origin student/ваше_имя
  ```
- Преподаватель проверит вашу работу и либо **примет PR** (нажмёт **«Merge pull request»**), либо **оставит комментарии** — в этом случае поправьте код и запушьте изменения заново

### Как отправить исправления в уже открытый PR

Отдельный PR создавать не нужно. Всё просто:

1. Внесите правки в файлы на своей ветке
2. Сохраните и закоммитьте:
   ```bash
   git add .
   git commit -m "Исправления после проверки"
   git push origin student/ваше_имя
   ```
3. Изменения автоматически появятся в уже открытом Pull Request, и тесты запустятся заново

## Автоматические тесты

При каждом Pull Request запускаются тесты:
- Проверка корректности решений (`pytest`)
- Проверка стиля кода (`flake8`)

### Как запускать тесты только по своим заданиям

Не нужно запускать все тесты курса сразу — проверяйте только ту тему, которую сейчас выполняете. Для этого укажите **номер своей папки** в команде.

Перед запуском убедитесь, что:

- вы перешли в папку репозитория (`cd python_basic_course`)
- установлены зависимости: `pip install -r requirements.txt`

Запуск для **вашего** модуля:

```bash
python -m pytest tests/test_01_python_basics -v   # модуль 1
```

Вместо `test_01_python_basics` подставьте свою папку из таблицы:

| Ваш модуль | Тесты для запуска |
|------------|-------------------|
| Модуль 1 | `tests/test_01_python_basics` |
| Модуль 2 | `tests/test_01_python_basics` |
| Модуль 3 | `tests/test_02_python_structures` |
| Модуль 4 | `tests/test_03_control_flow` |
| Модуль 5 | `tests/test_03_control_flow` |
| Модули 6–9 | `tests/test_04_paradigms` |
| Модуль 10 | `tests/test_05_api` |

> Что значат цифры в выводе: зелёные **PASSED** — задание выполнено верно, красные **FAILED** — есть ошибка. Смотрите текст ошибки и исправляйте решение.

Проверка стиля кода (`flake8`) запускается автоматически при Pull Request, локально её можно выполнить так:

```bash
python -m flake8 0*/practice/
```
