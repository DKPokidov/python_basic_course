## Логический тип данных

### Конъюнкция (Логическое умножение)

```python
print(f'False and False = {False and False}')
print(f'False and True = {False and True}')
print(f'True and False = {True and False}')
print(f'True and True = {True and True}')
```

### Дизъюнкция (Логическое сложение)

```python
print(f'False and False = {False or False}')
print(f'False and True = {False or True}')
print(f'True and False = {True or  False}')
print(f'True and True = {True or  True}')
```

### Инверсия (Логическое отрицание)

```python
print(f'False != False = {False != False}')
print(f'True != True = {True != True}')
print(f'False != True = {False != True}')
```

### Преоритет выполнения логических операций

Сначала выполняется:
1. Действие в скобках
2. Логическое отрицание
3. Конъюнкция (`and` — логическое умножение)
4. Дизъюнкция (`or` — логическое сложение)

```python
True and False or True
```

```python
True or False or True and False
```

```python
(True or False or True) and True
```

```python
True != False and True
```

```python
(True != True and False) != True and True or False
```

## Задача 13. Анализ списка зданий

Есть список зданий (кортеж словарей):

```python
buildings = (
    {"id": 1, "area": 1500, "floors": 5, "type": "жилой"},
    {"id": 2, "area": 800,  "floors": 3, "type": "офисный"},
    {"id": 3, "area": 2000, "floors": 8, "type": "торговый"},
    {"id": 4, "area": 1200, "floors": 4, "type": "жилой"}
)
```

Нужно одним выражением (без циклов и if) получить список id зданий, которые:

* имеют площадь ≥ 1000 м² **И**
* не менее 4 этажей **И**
* тип — "жилой".

```python
filtered = filter(
    lambda b: b["area"] >= 1000 and b["floors"] >= 4 and b["type"] == "жилой",
    buildings
)

selected_ids = list(map(lambda b: b["id"], filtered))

print(selected_ids)
```

## Задача № 14. Секретный код доступа

Вы — агент спецслужбы. Вам передали зашифрованное сообщение с кодом доступа к серверу. Код должен соответствовать строгим правилам безопасности. Ваша задача — проверить, является ли предоставленная строка валидным кодом доступа, не используя циклы и условные операторы.

Условия валидности кода:
* Длина строки — ровно 8 символов.
* Содержит хотя бы одну заглавную букву (A–Z).
* Содержит хотя бы одну строчную букву (a–z).
* Включает хотя бы одну цифру (0–9).
* Имеет ровно один специальный символ из набора: `#@#$%^&*`.
* Специальный символ не может стоять на первой или последней позиции.

```python
code = input('Введите код')
special_chars = "#@#$%^&*"

is_valid = (
    len(code) == 8
    and code != code.lower()
    and code != code.upper()
    and ('0' in code or '1' in code or '2' in code or '3' in code
           or '4' in code or '5' in code or '6' in code or '7' in code
           or '8' in code or '9' in code)
    and (code.count('#') + code.count('@') + code.count('$') +
          code.count('%') + code.count('^') + code.count('&') +
          code.count('*') == 1)
    and not code.startswith(('#', '@', '$', '%', '^', '&', '*'))
    and not code.endswith(('#', '@', '$', '%', '^', '&', '*'))
)

print(is_valid)
```
